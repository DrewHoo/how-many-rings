# Project notes for the agent

- What it is: a ranked board of every person on a college football national-championship staff since 1990, by the rings they can claim ("Nick Saban has seven. Scott Cochran, who ran his weight room, has eight."). A ring is a championship team-season whose staff roster the person appears on, still on staff at the title game; every ring carries its source page and the verbatim line. The data is researched, not refreshed: there is no cron, and a new season means a new harvest. README.md and `docs/data-pipeline.md` say how the rosters were gathered and why; `docs/research/scott-cochran.md` is the pilot case and the fixture the count has to reproduce.

- Data: `data/staffs/` is the harvested rosters, one file per championship team-season, each row with its receipts. The rules live beside them as data, not judgment: `employment-rules.json` (the job has to be the team; troopers, chaplains, consulting physicians and volunteers are out), `name-aliases.json` (one person spelled several ways), `player-rings.json` (titles won as a player, shown apart from the ranking), `school-colors.json` (cited brand hexes). `npm run fetch` (`scripts/build-site-data.mjs`) joins them deterministically into `public/data/rings.json` (gitignored, rebuilt on every build); no model counts anything. The `merge-*.mjs` scripts apply audited findings to the rosters.

- Code layout: Vite + React + TypeScript. `src/App.tsx` is the whole page (URL state in `useQueryState`: `scope`, `q`, `open`; the board; the Method; What to read next; the footer), `src/components/` the row, the ring glyphs and the share button, `src/lib/types.ts` the dataset shape and the scope rules, `src/lib/analytics.ts` the optional `track()` and `KOFI_URL`, `src/lib/siblings.ts` the other sports sites in the shared order (the page and llms.txt both read it). `src/index.css` is the stylesheet; `src/team-colors.css` is generated by `npm run gen:colors`.

- The page, top to bottom (the sports-site skill's anatomy): the h1, the dateline, the opening sentence; the filters (scope tabs, search, share); the board in two columns, a row opening inline to its receipts; the Method as `<section id="method">` with an open intro and four `<details>` folds (how a ring is counted, where the names come from, what the words mean, what we couldn't verify), the Ko-fi line open below them; What to read next from `SIBLINGS`; the footer. Ko-fi is tracked `kofi` with `from: 'notes' | 'footer'`; there is no icon bar.

- Build and deploy: `npm run build` is the data join, `tsc -b`, `vite build` and `scripts/prerender.mjs`, which renders the top 100 into `dist/index.html` with a seed the client hydrates against, and writes the JSON-LD, `sitemap.xml`, `llms.txt` and `dist/data/people.json` for the worker. There is no `npm test`; `tsc -b` is the check. `.github/workflows/deploy.yml` builds and deploys to GitHub Pages on every push to `main`, then the `worker` job deploys the share worker (skipped when `CLOUDFLARE_API_TOKEN` is missing). Dev server: `npm run dev` on 5173 (`.claude/launch.json`).

- The share worker (`worker/`, name `how-many-rings-og`) is routed over `drewhoover.com/how-many-rings/*`. For `?open=<id>` it rewrites the Open Graph tags to that person and points `og:image` at `og/<id>.png?v=<built>`, which it draws from `data/people.json` with resvg; everything else passes through. It reports `share unfurl` and `share card` to Mixpanel server-side, since the bot that fetches a link runs no script. `cd worker && npm run dev` runs it with `NO_REPORT=1`; `npm run preview -- <id>` draws cards into `worker/preview/`; `npm run typecheck` checks it.

- Look: this site keeps its own palette and faces on purpose. Onyx surface (`--bg #17150f`), ring gold as the one accent, school hues only on the ring marks, Georgia for the display face, Plex Mono for labels, the system sans for body. No Graduate, no Source Serif body, no stadium green. The og, cover and favicon art were drawn on this surface and match it. Do not restyle it to the other sports sites; take their chrome (the back bar, the sibling list, the Method folds, Ko-fi placements) and leave the colors.

- Prose on the page follows the existing copy: plain words, one fact per sentence, the role worded the way the source words it. A number on the page comes from `data.meta` or the rows, never typed in.
